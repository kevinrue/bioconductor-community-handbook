# Code of Conduct {.unnumbered}

The Bioconductor Code of Conduct was initially adapted from the [BioC 2020 Code of Conduct](https://bioc2020.bioconductor.org/code_of_conduct), which itself built on earlier conference-specific documents.

Changes to the Code of Conduct are versioned and tracked over time.

The community also maintains version-controlled translations of the Code of Conduct in several languages. Each translation corresponds to a specific version of the reference U.S. English document.

The multilingual versions of the Code of Conduct are available through the [Bioconductor multilingual Code of Conduct site](https://bioconductor.github.io/bioc_coc_multilingual/).
